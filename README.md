# Hallpass

A small restroom-pass prototype with student and teacher views.

## Live demo

Visit [Hallpass on GitHub Pages](https://28greenezk-sudo.github.io/hallpass-restroom-pass/).

## Try it

In Student view, choose a student and request a pass. Switch to Teacher view to approve or deny it. After approval, switch back to that student and check in when they return.

Pass activity is saved in the current browser with `localStorage`. It does not synchronize between devices or provide authenticated student and teacher accounts. The sample student names and teacher view are for demonstration only; do not use this prototype to manage real student passes. Real classroom use requires a secure shared backend and authenticated accounts.

The site deploys to GitHub Pages when changes are pushed to `master`. The first deployment may take a few minutes to finish.
